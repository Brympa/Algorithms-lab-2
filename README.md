# Лабораторная работа №2 — Рекурсивные алгоритмы

Интерактивное SPA-приложение на базе **.NET 10** и **Blazor WebAssembly**, демонстрирующее работу классических рекурсивных алгоритмов, сравнение рекурсивных и итеративных подходов, визуализацию и профилирование производительности в реальном времени.

---

## 🚀 Быстрый запуск

### Вариант 1. Через bat-файл (в один клик на Windows)
Просто запустите файл в корне репозитория:
```cmd
run.bat
```
Скрипт автоматически проверит SDK, выполнит быструю сборку и откроет веб-приложение по адресу [http://localhost:5068](http://localhost:5068).

---

### Вариант 2. Через командную строку
Требуется установленный [.NET SDK 10](https://dotnet.microsoft.com/download):

```bash
# 1. Сборка решения
dotnet build

# 2. Запуск приложения
dotnet run --project src/AlgorithmsLab2.Web

# 3. Запуск unit-тестов
dotnet test
```

После запуска перейдите в браузере по адресу: **`http://localhost:5068`**.

## 📌 Основные разделы приложения

### 1. Фракталы — Кривая Госпера (Flowsnake)
- **Суть:** Гексагональная кривая, заполняющая плоскость, строится через взаимную рекурсию подкривых $A(n)$ и $B(n)$ с углом поворота $60^\circ$ ($7^n$ сегментов).
- **Порядок до 100:** Поддерживает порядок $n$ от 0 до 100.
  - Точный математический расчёт числа сегментов через `BigInteger` ($7^{100} \approx 3.23 \times 10^{84}$) с экспоненциальной нотацией.
  - Безопасный субпиксельный рендеринг геометрии для $n \ge 7$ ($823\,543$ сегмента) без риска переполнения памяти (OOM) и зависания браузера.
- **Пошаговая постройка:** Плеер с покадровым воспроизведением (Play/Pause), кнопками шага вперед/назад, ползунком прогресса ($0\% \dots 100\%$) и регулятором скорости ($0.5\times \dots 10\times$).
- **Интерактивная карта (Pan & Zoom):** Масштабирование колёсиком мыши относительно курсора, перетаскивание холста (drag), двойной клик для сброса и экранные HUD-кнопки `[+]`, `[−]`, `[⊡ Обзор]`, `[⟲ Сброс]`.

### 2. Ханойские башни (Ханой)
- **Суть:** Классическая головоломка перемещения стопки из $N$ дисков со стержня $A$ на стержень $C$ ($N \le 8$, минимальное число ходов $2^N - 1$).
- **Сравнение алгоритмов:**
  - **Рекурсивный метод:** Каноническое решение с глубиной стека вызовов $O(N)$.
  - **Итеративный метод со стеком (доп. задание):** Симуляция стека фреймов без использования системного call-stack.
- **Визуализация:** Интерактивная 2D-анимация перемещения дисков на Canvas с пошаговым воспроизведением ходов.

### 3. Командные алгоритмы
Каждый алгоритм снабжен интерактивной визуализацией, теоретической справкой и потоковым замером производительности:
1. **Разбиение числа на слагаемые (Integer Partitions):**
   - Рекурсивный поиск разбиений числа $N$.
   - Визуализация в виде **диаграмм Юнга (Ferrers)**.
2. **Дерево Штерна–Броко (Stern–Brocot Tree):**
   - Рекурсивный обход бинарного дерева всех взаимно простых дробей через медианты $\frac{m_1+m_2}{n_1+n_2}$.
   - Интерактивная карта дерева (Pan & Zoom) с масштабированием, подсветкой пути поиска и автоцентрированием.
   - Два честных режима замера: **Генерация дерева** $O(2^N)$ и **Поиск дроби** $O(N)$ с фильтрацией погрешности системного таймера.
3. **Умножение Карацубы (Karatsuba Multiplication):**
   - Метод «Разделяй и властвуй»: сокращение 4 умножений половинных чисел до 3.
   - Визуализация дерева рекурсивного ветвления с формулами разбиения $X$ и $Y$.

### 4. Бенчмарки в реальном времени
- Замеры выполняются асинхронно потоками (`IAsyncEnumerable`) без блокировки UI-потока браузера.
- График на Canvas 2D обновляется в **реальном времени** во время проведения серий замеров.
- Интерактивные всплывающие тултипы при наведении на точки графика (номер замера, $N$, время в мс/с).
- Полная таблица замеров с автоматической прокруткой и экспортом данных в JSON.

## 🧪 Тестирование

Проект покрыт исчерпывающим набором модульных тестов:
```bash
dotnet test
```
Тесты проверяют:
- Математическую эквивалентность рекурсивного пути Госпера канонической L-системе;
- Корректность генерации для порядков от 0 до 100 и защиту от OOM;
- Совпадение последовательностей ходов Ханоя между рекурсивным и стековым алгоритмами;
- Корректность умножения Карацубы, поиска дробей Штерна–Броко и генерации разбиений;
- Стабильность и точность замеров таймингов.
